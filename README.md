# go-git-cli
- This is a simple TUI based project built using BubbleTea, to list all the git branches for a particular repository.

## Get the project
```bash
git clone https://github.com/Adityasinghvats/git-list.git
```
```bash
cd git-list
```
- Run the program
```bash
go run main.go
```
